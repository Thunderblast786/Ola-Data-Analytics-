# Ola Data Analytics Dashboard
1. Project Title / Headline

🚕 OLA Data Analytics Dashboard: Ride, Revenue & Customer Insights

An interactive Power BI dashboard designed to analyze OLA ride performance, booking trends, revenue, cancellations, and customer ratings.

2. Short Description / Purpose

The OLA Data Analytics Dashboard provides a comprehensive view of ride bookings and business performance across different booking statuses, vehicle types, dates, and customer interactions. It helps business analysts and decision-makers identify ride trends, revenue performance, cancellation patterns, and customer satisfaction.

3. Tech Stack

The dashboard was built using the following tools and technologies:

📊 Power BI Desktop – Main platform for dashboard creation and visualization.
📂 Power Query – Used for data cleaning, transformation, and preparation.
🧠 DAX – Used for KPIs, calculated measures, and analytical calculations.
📁 Excel/CSV – Used as the primary data source.
📈 Data Visualization – Charts, cards, slicers, tables, and interactive visuals.
4. Data Source

Source: OLA Ride Booking Dataset

The dataset contains ride booking information including booking date, booking status, vehicle type, booking value, customer details, cancellation reasons, driver information, and customer ratings.

The data is structured to analyze ride volume, revenue, cancellations, booking success, and customer experience.

5. Features / Highlights
• Business Problem

OLA generates a large volume of ride-booking data, making it difficult to quickly identify booking performance, revenue trends, cancellation patterns, and customer satisfaction.

Key questions include:

Which booking status has the highest percentage?
Which vehicle types generate the most bookings?
What are the major reasons for cancellations?
How does ride volume change over time?
Which factors affect customer satisfaction?
• Goal of the Dashboard

To create an interactive dashboard that:

📊 Monitors overall booking performance.
🚗 Analyzes ride volume by vehicle type.
💰 Tracks booking value and revenue.
❌ Identifies customer and driver cancellation patterns.
⭐ Analyzes customer ratings and satisfaction.
📅 Tracks booking trends over time.
• Walkthrough of Key Visuals

Key KPIs (Top Section)
Total Bookings, Total Booking Value, Successful Bookings, Cancelled Bookings, and Average Customer Rating.

Booking Status Breakdown (Pie Chart)
Shows the distribution of successful bookings, driver cancellations, customer cancellations, and driver-not-found bookings.

Ride Volume Over Time (Line Chart)
Displays daily booking trends and helps identify changes in ride demand.

Vehicle Type Analysis
Compares bookings and booking value across different vehicle categories.

Revenue Insights
Analyzes total booking value and revenue performance across rides and vehicle types.

Cancellation Analysis
Highlights cancellation trends and identifies the major reasons behind unsuccessful bookings.

Customer Ratings
Analyzes customer feedback and rating patterns to understand overall service satisfaction.

• Business Impact & Insights

Ride Optimization: Identify high-demand ride categories and booking patterns.

Revenue Optimization: Monitor booking value and identify high-performing vehicle types.

Cancellation Reduction: Understand major cancellation reasons and improve service efficiency.

Customer Satisfaction: Track ratings and identify areas for improving customer experience.

Operational Decisions: Use booking trends to improve driver availability and ride allocation.
